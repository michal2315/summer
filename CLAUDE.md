# Summer

## Rules

- **Verify** changes by type-checking (`npx tsc --noEmit`) and building (`npx ng build` in summer-client). Tests are
  allowed: server `npx jest src` (unit) in summer-server, client `npm run test:ci` in summer-client.
- **No docs.** Don't write or update documentation (README, `docs/`, `DECISIONS.md`, API notes) unless asked.
